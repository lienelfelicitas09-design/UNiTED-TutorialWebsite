HTML Introduction

HTML means HyperText Markup Language. It gives a webpage its structure and content. HTML uses elements written with tags. Most elements have an opening tag, content, and a closing tag.

Remember: HTML = structure; CSS = appearance. A browser reads HTML and displays the page.

HTML · LESSON 4

Links and Images

The a element creates a link. The img element displays an image. The href attribute gives a link destination; src gives an image location; alt describes the image.

Remember: Use meaningful link text and helpful alt text. Use an image URL or a file saved beside your HTML file.

CSS · LESSON 10

Margin, Padding, and Borders

The CSS box model describes each element as content surrounded by padding, border, and margin. Padding is inside the border; margin is outside it.

Remember: Use padding to add space inside a box and margin to separate it from other elements. Border draws an outline.

CSS · LESSON 11

Classes, IDs, and Selectors

A selector tells CSS which HTML elements to style. A class starts with a dot (.) and can be reused. An ID starts with # and should identify one unique element on a page.

Remember: Use classes for styles shared by several elements. Use IDs for unique page elements and for linking or scripting when needed.

CSS · LESSON 12

Layout and Flexbox

CSS layout tools help arrange content. Flexbox is useful for placing items in a row or column and controlling alignment and spacing.

Remember: Set display: flex on a parent. Use gap for space, justify-content for the main direction, and align-items for cross-axis alignment.

Responsive Design

Responsive design makes a website work on different screen sizes. Use the viewport meta tag, flexible widths, and media queries to adjust layouts for smaller screens.

Remember: Try resizing the preview area or opening the page on a phone. Avoid fixed widths that are wider than the screen.
